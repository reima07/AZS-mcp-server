# 변경 이력 (Client)

## [v0.3.1] - 2025-01-12
### 추가됨
- **🤖 LLM 기반 자연어 처리**: OpenAI GPT-4o-mini 통합
- **🔄 동적 MCP 툴 정보**: 서버에서 실시간 툴 목록 및 설명 조회
- **📋 동적 구독 매핑**: 사용자별 실제 구독 목록 기반 자동 매핑
- **💬 자연스러운 대화**: 인사말, 일반 대화, Azure 작업 요청 모두 지원
- **🛠️ JSON 파싱 개선**: 마크다운 블록 제거 및 에러 처리
- **🎯 엔터키 중복 입력 방지**: UI 개선

### 변경됨
- **의도 파싱 방식**: 룰 기반 → LLM 중심으로 전환
- **구독 선택 로직**: 하드코딩 → 동적 매핑으로 개선
- **사용자 경험**: 기계적 응답 → 자연스러운 대화로 개선

### 수정됨
- **의존성 충돌**: starlette, langchain-core 버전 호환성 문제 해결
- **환경변수 로드**: graph.py에서 .env 파일 로드 문제 해결
- **메모리 초기화**: AgentOrchestrator 초기화 순서 문제 해결
